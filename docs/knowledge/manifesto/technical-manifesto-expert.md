# 技術宣言書(専門家向け) — it-hercules-laboratory

> 本文書は法的助言ではない。技術思想の公知化を目的とした社内ドラフトである。

## 1. AI ファースト(P1)

最大の読者は人間ではなく AI エージェントである。すべての正本は機械可読(JSON Schema・
frontmatter 付き Markdown)とし、人間向けの HTML・要約・ダッシュボードは正本から生成される
**生成物**として扱う。生成物の手編集は禁止し、CI が GENERATED ヘッダとの乖離を検知する。

## 2. Truth は repo の外(P2)

永続的な正本データ(イベント)は Cloudflare R2 の append-only ストアにのみ存在する。
リポジトリが持つのはスキーマ(契約)と、そのイベント列から画面表示用のビューを再生成する
純粋関数のみである。UPDATE/DELETE は行わない — 履歴は破棄せず積み上げる。

## 3. 10年間ユーザーが増えなくても賄えるコスト構造(V3-CST-01)

ユーザー数に比例して増える従量課金(embedding API 等)を避け、計算資源はユーザー端末側へ
寄せる。サーバーレス(Cloudflare Pages/Workers/R2)中心 + 最小 VPS(メール・Webhook 中継のみ)
で運営コスト月 300〜1000 円規模を目標とする。これは単なる節約ではなく、**ユーザーが増えなくても
文明が死なない**という持続性の設計原則である。

## 4. フォーク文化(V3-FND-16)

全構成(コード・データ・設定)を置換しても同一文明であり続けることを前提に設計する
(R2 の Truth データそのものは fork 不可の神域とする)。既存の `forked_from` パターンは
テンプレート・掲示板投稿・研究プロジェクトなど複数ドメインへ横展開されており、
「一からコピーして自分の文明を作れる」自由を構造で担保する。

## 5. 人間ゲート(V3-AIP-31)

AI は補助であり決定者ではない。ワンクリック全自動を禁止し、以下は必ず人間が最終判断を行う:
公開の実施・本番鍵/実鍵投入・金銭・物理鍵・撤回台帳の復活・常駐的なトークン消費の開始。
AI が判断を保留すべき場面では、勝手に推測で埋めず「保留」として明示的に記録する
(誇張ゼロ・ブラックボックス禁止)。
