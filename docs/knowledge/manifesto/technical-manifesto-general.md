# it-hercules-laboratory は、どんな考え方で作られているか(やさしい版)

> 本文書は法的助言ではない。it-hercules-laboratory(以下「このサービス」)がどんな考え方で
> 作られているかを、専門知識がなくても分かるように説明したものです。

## 1. 「記録は消さない、ためていく」

このサービスでは、何かを変えたり訂正したりしても、前の記録は消しません。あとから
「いつ・なぜ変わったのか」を誰でも読み返せるようにするためです。日記を上書きせず、
ページを増やしていくイメージです。

## 2. 「10年後もお金の心配をしなくていいように」

利用者がたくさん増えなくても、運営を続けられる仕組みにしています。利用者が増えるたびに
費用が跳ね上がる作り方は避け、なるべく利用者自身のパソコン・スマホの力を借りる設計に
しています。

## 3. 「まるごと自分のものにして、育て直せる」

このサービスの仕組みは、誰かが「自分用に作り直したい」と思ったときに、まるごとコピーして
自分の世界を作れるようになっています(記録そのものは特別に守られていて、勝手にコピー
できません)。木を接ぎ木するのではなく、種から新しい木を育てられる、というイメージです。

## 4. 「AIにすべて任せない」

AIは手伝ってくれますが、最後に「これでいいですか?」と決めるのは必ず人間です。特に、
公開する・お金が動く・鍵となる情報を使う、といった重要な場面では、AIが勝手に進めることは
ありません。AIが迷ったときは「分かりません」と正直に言うようにしています。
