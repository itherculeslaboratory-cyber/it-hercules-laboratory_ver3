# ArticleNode言語レイヤー(V3-WIK-35・設計ドラフト・未実装)

> **誇張ゼロ**: 本ページは設計ドラフトのみである。記事の自動生成・アフィリエイト連携の
> 実コードはこの艦(docs/knowledge・design/adr 専用・コード編集不可)の書いてよい場所の外に
> あり、未実装のまま持ち越す。

## 要件(再掲)

> 論文データ・観測データ・種族/市場文化から初心者向け情報(買う場所・種族名の読み・土・育成期間・
> 胸角サイズ・飼育容器サイズ等)をまとめた記事を事実ベースで自動生成し、論理的根拠に基づく商品
> おすすめ(アフィリエイト)を付け、記事から動画も自動生成する。記事は文明の知識を人間可読形式に
> 翻訳する「言語レイヤー」(ArticleNode)の中心とし、愚痴スレッドのまとめも記事アイデアにする。

【第20回2026-07-31 GD-2確定】「記事から動画も自動生成」の部分は IHL.ver3video へ分離。
本体(ver3実装対象)は記事生成部分のみ(本ドラフトも記事生成部分に限定する)。

## 設計方針(ドラフト)

1. **ArticleNode を新規イベント型としては作らない**。既存の `content`/`plaza-post` 投影
   パターン(`unified-search-rag.md` が既に定義した「観測/wiki/掲示板/UI/テンプレートを
   同一384次元embedding空間で検索する」設計)に載せ、`content` の一種(kind=`article`)として
   位置づける(reuse-first・新規ストレージ層を作らない)。
2. **事実ベースの根拠付け**: 記事内の各主張(買う場所・育成期間・胸角サイズ等)は、元になった
   Truth イベント(研究論文の該当節・観測記録の集計値)への Citations を必須とする(本バンドルの
   「出典必須」規約をそのまま適用。捏造禁止)。
3. **アフィリエイト推薦の根拠付け**: 「論理的根拠に基づく」の担保として、推薦理由を機械可読な
   フィールド(例: `reason_basis: "育成期間の実測分布"`)として記事メタデータに残し、根拠なき
   推薦を出さない(誇張ゼロの延長)。
4. **愚痴スレッドのまとめ→記事アイデア化**: 既存の掲示板(BBS)集計機能(`plaza-stats-routes.ts`)
   が持つ投稿集計の仕組みを流用し、頻出トピックを記事候補として抽出する運用を想定する
   (新規の常時稼働バッチではなく、既存の集計結果を人間/エージェントが記事化検討に使う運用)。
