it-hercules-laboratory(以下「IHL」「本サービス」)は、ユーザーのプライバシーを尊重し、以下の方針に
従って個人情報を取り扱います。

## 1. 収集する情報

本サービスが収集する情報は、以下の項目に限定します
(`apps/api/src/policy.ts:167-174` の `DATA_COLLECTION_ITEMS` 定数と一致させる)。

| 項目 | 内容 |
|---|---|
| `email` | アカウント連絡用のメールアドレス |
| `country` | 利用国 |
| `language` | 表示言語設定 |
| `screen_transition_log` | 画面遷移ログ |
| `post_history` | 投稿履歴 |
| `ai_usage_log` | AI機能の利用ログ |

上記以外の項目を収集する場合は、`apps/api/src/policy.ts` の `DATA_COLLECTION_ITEMS` を更新し、本文書も
同時に更新すること(コードと文書の不整合を作らない)。

## 2. 利用目的

行動ログ(`screen_transition_log` 等)の利用目的は、以下に限定します
(`apps/api/src/policy.ts:177-178` の `LOG_PURPOSE_ALLOWED` 定数と一致させる)。

- `service_improvement`(サービス改善)
- `fraud_prevention`(不正防止)

**広告目的での利用は行いません。** 上記以外の目的で行動ログを利用する場合は、`LOG_PURPOSE_ALLOWED` の
更新とユーザーへの再同意取得(`terms-version-management.md` 参照)を要します。

## 3. GitHub連携によるログイン情報

GitHubアカウントでログインした場合、GitHubユーザー名とIHLユーザーIDの対応関係を、本サービスの内部運用
(本人確認・サポート対応等)にのみ利用します。この対応関係を外部へ公開・第三者提供することはありません。

## 4. 第三者提供

法令に基づく場合を除き、ユーザーの同意なく個人情報を第三者に提供することはありません。

## 5. 保管・削除

1. 個人情報は、本サービスの提供に必要な期間保管します。
2. ユーザーがアカウント削除を申請した場合、[削除完了までの期間・削除対象範囲を記入]に従って対応します。
