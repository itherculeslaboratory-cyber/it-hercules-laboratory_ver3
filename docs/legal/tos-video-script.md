# it-hercules-laboratory 利用規約(動画版 台本) [社内ドラフト]

> **本文書は法的助言ではない。社内向けの社内ドラフトである。**
> **動画版は理解を助けるための補助表現です。契約上の効力を持つのは法的版(`tos-legal.md`)だけです。**

## 位置づけ(V3-SEC-21/SEC-22)

利用規約の3形態(法的版/やさしい版/動画版)のうち、動画版の台本と、条文セクションから動画URLを
解決する resolver 層(`resolveTermsMediaUrl` / `apps/api/src/policy.ts:145-152`)向けのマッピング表を
本文書で定義する。

`resolveTermsMediaUrl(rows, terms_version, section_id, media_kind)` は
`terms_version + section_id + media_kind` の組み合わせに一致する行の `resolved_url` を返す(無ければ
`null`)。版が変わってもこの表に行を追加するだけで規約本文に動画URLを直書きしなくてよい設計になっている
(policy.ts のコメントどおり)。

## section_id 命名規則

`tos-legal.md` の条番号に対応させ、`art<条番号>-<英語スラッグ>` の形式で採番する(例:
`art1-apply` = 第1条(適用))。

## 誇張ゼロの明記

- 上記の `resolved_url` は本ドラフト段階では未収録(実際の動画は未制作)。動画制作・URL登録は人間ゲート
  (`human-review-checklist.md` 参照)を経てから行う。
- この表を `TermsMediaRow[]` としてAPI側に投入する際は、`resolved_url` が全て埋まってから投入すること
  (空文字列・プレースホルダのまま本番投入しない)。
