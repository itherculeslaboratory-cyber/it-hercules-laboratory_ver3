# 利用規約/プライバシーポリシー 公開前 人間確認チェックリスト [社内ドラフト]

> **本文書は法的助言ではない。** このチェックリスト自体も社内ドラフトであり、実際のレビュー担当者
> (弁護士・経営層)が独自の判断で項目を追加・修正してよい。

対応する進捗ID: `V3-SEC-25`(利用規約/プライバシー法務ドラフト+人間確認チェックリスト)。
`docs/planning/c8/progress.json` の `tc` は空配列(`[]`)= テスト対象外(文書レビューは自動テストで
検証できない性質のため)。本艦は**文書の作成まで**を完了条件とし、以下のチェック実施そのものは
人間ゲートとして未実施のまま引き渡す。

## 公開前に必ず確認すること(人間ゲート)

- [ ] `tos-legal.md` の `[運営者名を記入]`・`[準拠法を記入]`・`[管轄裁判所を記入]`・
      `[問い合わせ先を記入]` の全プレースホルダが、実在する法人登記情報・実際の連絡先で埋まっている。
- [ ] `privacy-policy.md` の `[削除完了までの期間・削除対象範囲を記入]`・`[問い合わせ先を記入]`・
      Cookieポリシー節のプレースホルダが埋まっている。
- [ ] `tos-video-script.md` の動画マッピング表の `resolved_url` が、実際に制作・公開された動画の
      URLで全行埋まっている(空欄・プレースホルダのまま本番の `TermsMediaRow[]` に投入しない)。
- [ ] 弁護士(または顧問弁護士)によるレビューを受けている。
- [ ] `tos-legal.md`(法的版)・`tos-easy.md`(やさしい版)・`tos-video-script.md`(動画版)の間で、
      内容の実質的な矛盾がないことを目視確認している(やさしい版・動画版が法的版より広い権利を
      約束していないか、等)。
- [ ] `privacy-policy.md` の収集項目表・利用目的が、実際にコード側で収集・利用している内容
      (`apps/api/src/policy.ts` の `DATA_COLLECTION_ITEMS`/`LOG_PURPOSE_ALLOWED`)と一致している
      (コード変更時にこのチェックリストへ差し戻っての再確認を忘れない)。
- [ ] `terms_version` が `tos-legal.md`/`tos-easy.md`/`tos-video-script.md`/`privacy-policy.md` の
      4文書で一致している。
- [ ] 公開日(`effective_at`)が確定し、既存ユーザーへの再同意フロー
      (`terms-version-management.md`)が実際に route実装(consent-routes.ts、w1-aut所有)へ
      反映されていることを確認している(本艦はここまで確認できていない=持ち越し)。
- [ ] IHL独立性(V3-SEC-27): civilization-os の規約文書からのコピー・流用箇所が無いことを
      最終レビュー者自身の目で確認している(本艦は執筆時点でcivilization-os文書を一切参照していない
      旨を`README.md`に記載済みだが、レビュー者による独立確認を推奨する)。
