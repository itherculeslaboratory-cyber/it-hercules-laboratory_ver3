# docs/legal — 法務文書ドラフト一式(社内ドラフト・索引)

> **本ディレクトリの全文書は法的助言ではない。社内向けの社内ドラフトであり、弁護士等の専門家によるレビューと
> 経営判断による公開承認(人間ゲート)を経るまでは、外部公開・確定版として扱わない。**

## 位置づけ

このディレクトリは it-hercules-laboratory（以下「IHL」）サービスの利用規約・プライバシーポリシー関連の
社内ドラフトを集約する。作成の経緯は `docs/planning/c8/progress.json` の `V3-SEC-21`/`V3-SEC-22`/
`V3-SEC-23`/`V3-SEC-25`/`V3-SEC-27` を参照(w2-sec 艦が API 側の型・関数(`apps/api/src/policy.ts`)を
実装済みで、法的文書の本文作成のみが `docs/legal/` 相当としてこの艦へ持ち越されていた)。

## 三形態の関係(V3-SEC-21)

利用規約は「法的版」「やさしい版」「動画版」の3形態で提供する。**契約上の効力を持つのは法的版のみ**
(`apps/api/src/policy.ts` の `TERMS_KIND_LEGAL` 定数どおり)。やさしい版・動画版はユーザーの理解を
助けるための補助的な言い換えであり、法的版と内容が食い違う場合は法的版が優先する旨を各文書に明記する。

## 独立性の宣言(V3-SEC-27)

この一式は civilization-os の規約文書からのコピー・流用を一切行わず、IHL サービスの実際の機能
(GitHubログインによる個体登録、世界/経済コイン投票、多言語UGC投稿、研究論文投稿、個体観察記録、
アフィリエイト等)に基づいて新規に起こした。構造的独立性(civilization-os 規約への参照0件)は
API 側テスト(`tests/sec-w2-batch.test.ts`)で既に確認済み(w2-sec R0731-dd313c)。
